# Одноразовая подготовка сервера для приложения Битрикс24

`prepare_spravka.py` добавляет конфигурацию приложения «Справка по мероприятиям» №445 на существующем VPS SpaceWeb. По умолчанию выполняется только проверка; запись новых файлов требует отдельного запуска с `--apply` от root.

## Границы изменения

- **Отдельное окружение:** `/etc/interpain-spravka-bitrix.env`, root, `0600`; фиксированный публичный client_id, `SPRAVKA_B24_ENABLED=0`, путь каталога состояния.
- **Дополнение systemd:** `/etc/systemd/system/interpain-b24forms.service.d/40-spravka-bitrix.conf`, root, `0644`, подключает новый environment file после прежнего `.env`.
- **Закрытое состояние:** `/var/lib/interpain-spravka-bitrix`, www-data, `0700`.
- **Без перезапуска:** только `systemctl daemon-reload`; PID и HTTP-проверки сверяются до и после.

Прежний `.env` не читается и не меняется. Код сайта, пароль, вебхук, Nginx, Docker, SSH и firewall не изменяются. Новые переменные попадут в процесс приложения лишь при следующем отдельно согласованном перезапуске; вход через Битрикс24 останется выключенным.

## Запуск после разрешения

Скачивайте файл из точного коммита, а не изменяемой ветки. Сверьте SHA-256 перед выполнением, не передавайте незавершённую загрузку напрямую в Python.

```bash
python3 /root/prepare_spravka.py
python3 /root/prepare_spravka.py --apply
```

Успех отмечается `SPRAVKA_SERVER_PREPARED_OK`. При отличающихся существующих файлах, симлинках, неожиданных environment files или небезопасных правах установщик остановится, а не заменит чужую конфигурацию. При ошибке после начала записи удаляются только новые объекты этого запуска; прежний каталог состояния и его содержимое не удаляются.

## Тесты

```bash
python3 -m unittest discover -s deploy/spaceweb/tests -v
```

Новые тесты работают во временных каталогах и моделируют привилегии и systemd. Они не заменяют фактический результат запуска на VPS. Публикация этого файла сама по себе не запускает установку, выпуск или перезапуск.
