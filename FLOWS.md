# Проверки изменения «Справка»

## Существующая регистрация
- `/event-register/?EVNUMBER=323`: загружается страница регистрации.
- Пустой EVNUMBER: понятное сообщение, форма не создаёт заявку.
- Существующие API мероприятий и загрузчика проходят unit-тесты.
- Не отправлять реальные регистрационные формы при проверке.

## Справка
- `https://forms.eduinterpain.ru/spravka`: вход в существующем Node.js-сервисе, пароль не сохраняется в браузерных хранилищах.
- HTML и шрифт загружаются с того же сервера; нет runtime-зависимости интерфейса от внешних CDN.
- Без пароля, неверный пароль, отсутствующий серверный пароль: данные недоступны.
- После входа: только стадия «Реализация», сортировка по коду, четыре строки каждого блока.
- Заголовок каждого блока: ID паспорта | кодовое обозначение | кликабельное название | город.
- Для карточки 323 заголовок начинается с `323 | 26_11_07-08 |`; ID не меняет сортировку.
- Название открывает карточку мероприятия в новой вкладке.
- Обновить повторно запрашивает справку; выход убирает данные и пароль из памяти.
- Пустая выборка, недоступный API, отсутствующая стадия или поле: явное сообщение, не ложные нули.
- Проверить на ширинах 1360 и 375 px, длинное название и код, отсутствие горизонтального переполнения.
- Живые подсчёты требуют проверки на хостинге: секрет вебхука в этой среде не предоставлен.
- Регрессия фильтра: сделки запрашиваются по одному паспорту через скалярное равенство,
  не через IN по пользовательскому полю; фильтр стадий и полная пагинация сохранены.
- Общая сделка с множественной привязкой учитывается по одному разу для каждого паспорта,
  даже если повторяется в ответах на разные запросы.

## Копирование для мессенджера
- Актуальный интерфейс: по чекбоксу перед каждым мероприятием, «Выбрать все»
  с промежуточным состоянием и одна кнопка «Скопировать».
- Без выбора кнопка серая и disabled; выбор хотя бы одного делает её синей и активной.
- Копируются только отмеченные мероприятия в исходном порядке, независимо от порядка
  кликов. Общий чекбокс отмечает все и снимает все; частичный выбор показывает mixed.
- Проверить клавиатуру (Tab/Space), мобильные области нажатия, счётчик выбранного.
- Обновление сохраняет выбор существующих ID, удалённые ID исключаются; выход очищает выбор.
- Нижеследующие проверки отдельных старых кнопок относятся к предыдущей итерации.

### Результат итерации с чекбоксами
- 23 теста Node пройдены, включая два дополнительных теста выбранного подмножества:
  исходный порядок, нормализация ID, отказ для пустого/устаревшего выбора.
- Chromium: начальный пустой выбор, одно/все/часть, снятие всех, Space на чекбоксе,
  счётчик, единственная кнопка, реальное чтение буфера с выбранным подмножеством.
- Проверены: сохранение выбора при обновлении, исключение пропавшего ID, пустая
  выборка, ошибка с предупреждением в тексте, блокировка во время загрузки,
  очистка при выходе и 401, повторный вход без старого выбора, раскрытие правил.
- Резервный диалог содержит только выбранные мероприятия; Escape очищает текст.
- Desktop 1360 px и mobile 375 px просмотрены; переполнения и новых pageerror нет.
- Производственный сайт и GitHub не изменены: пользователь выбрал только предпросмотр.
- «Скопировать справку»: один клик записывает обычный текст всей загруженной справки,
  с датой её обновления, исходным порядком мероприятий и всеми четырьмя показателями.
- «Скопировать» в каждом мероприятии: только его ID, код, название, город и четыре строки;
  другие мероприятия, кнопки, HTML и учётные данные в буфер не попадают.
- Нулевые значения сохраняются. Успех явно подтверждается, без ложного сообщения при отказе.
- Проверить реальные clipboard write/read и вставку в текстовое поле после кликов.
- При отказе Clipboard API работает резервный copy; при полном запрете открывается
  диалог с выделенным текстом, закрытие и Escape очищают поле и возвращают фокус.
- Обновление блокирует копирование; после него берутся новые данные.
  Ошибка обновления сохраняет старую дату и добавляет предупреждение при копировании.
- Пустая выборка: кнопка копирования недоступна, карточек и их кнопок нет.
- Выход и 401 очищают модель справки, диалог и подтверждение. Поздний результат
  асинхронного копирования не возвращает данные после выхода.
- Проверить desktop 1360 px и mobile 375 px, длинное название, кнопки и диалог без
  горизонтального переполнения; перезагрузка и повторный вход продолжают работать.
